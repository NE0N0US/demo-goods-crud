# Тестовое задание «Управление товаром»

## Установка зависимостей и запуск
```bash
npm i && npm start
```

## Сборка
```bash
npm run build
```

## Описание
- CRUD для товаров, с валидацией;
- Angular 20 Standalone, NgRx, Bootstrap 4;
- Имитация серверного API, адаптивная вёрстка, индикация загрузки, вывод ошибок.
